## 两条链

**外环 · 产业外链（深蓝）**

> 数据 → 训练 → 模型 → 调用 → 部署 → 产品 → 成本 → 安全

**内环 · 运行内链（青绿）**

> 切块 → 向量化 → 排位置 → 找关系 → 深加工 → 算概率 → 做选择 → 接回去

## 5 分钟总纲（先看懂 AI）

点顶部「5 分钟总纲」打开，四个页签：

1. **总纲**：三句话说清 AI——看上文猜下一个词 → 接回去循环 → 训练改参数、调用不改参数；外加「外环 = 海岸线、内环 = 水流」的比喻。
2. **训练 vs 调用**：一张对比表，回答“AI 是不是每次都在学”。
3. **AI 为什么会胡说**：幻觉的三个原因 + 五种减法。
4. **5 问自检**：当场做题，答对说明已经掌握主干。

## 视觉与声音

- **柔和蓝海天场景**：天空 → 海面的大渐变，地平线暖光 + 暖日，冷蓝与暖金对比，亮而不刺眼
- **六层动态**：天空薄雾、光柱、地平线暖光、水面焦散光纹、近景海浪、浮游光点 + 暗角；节奏很慢，像循环播放的视频，降低焦虑
- **景深元素**：云、远山岛屿、海鸥、一条小帆船、两侧水母、前景礁石与海草——让海“活着”，不至于只有渐变
- 窄屏会自动隐藏水母和礁石，避免抢画面
- 环上的小箭头表示方向（已去掉环上流动的小虚点）
- **流水声**由 Web Audio 实时合成（滤波噪声 + 缓慢起伏），不依赖任何音频文件
- 节点是 3D 透视的发光球体，外环深蓝、内环青绿、选中转金色
- **手机 / 窄屏**：自动拉远镜头，两条环完整显示；图例隐藏，说明页与面板改为窄屏排版
- **大字模式**：一键放大面板、名词库、总纲和说明页的文字

### 点线面怎么用的（设计说明）

- **点**：行星 = 点缀；选中节点脉冲 = 信息聚焦；水面碎光 / 浮游光点 = 氛围点缀
- **线**：地平线 = 信息分割；光柱 = 视线引导；环与轨道 = 信息连接；焦散光纹 = 肌理
- **面**：海天渐变 = 背景面；中心光晕 = 信息衬托；暗角 = 画面分割与聚焦；海浪 = 画面下缘的“面”
- **构成形式**：重复-渐变（环、行星、海浪、薄雾）、特异（金色选中节点）、发散（光柱、轨道）、对比-肌理（光滑渐变 vs 水纹）、对比-大小-对抗（大球 vs 小球、冷蓝 vs 暖金）、同构（圆环 ↔ 水波涟漪）
- **画面重心**：中心光晕 + 暖日 + 暗角，把视线收在「学海无涯」和双环上

## 新手引导与渐进披露（给第一次看的人）

第一次点「开始探索」后会走 **3 步引导**，每步只聚光一个地方：

1. 外环：这 8 个环节是 AI 从数据到安全的产业链
2. 一个大球：点它，看它周围的名词行星
3. 顶部「名词库」：想按顺序查 64 个词就点这里

引导可随时「跳过」，点「介绍 → 开始探索」可以重看。

**面板渐进披露**：点节点后默认只显示「生活例子 + 一句话含义 + 为什么有这一步」，想深看再点「展开更多：依据 / 结论 / 关系 / 本环节名词」。

**小行星可发现**：行星做得更大、带脉冲光圈，引导结束后会弹一句提示「点小球看解释」。

**给新手的优先级**：名词库顶部有「新手必看 10 词」，点过的词会打勾，显示「已学 x/10」。

**阅读模式**：打开面板 / 名词库 / 总纲 / 引导时，背景会自动降亮一档，避免动效抢注意力。

## 名词卫星（每个大环节周围的小行星）

外环 8 个大环节是「太阳」，名词库里的 64 个词是绕它们转的「行星」，按该环节内的运行顺序排布：

- **同一条轨道**：每个环节的所有行星都跑在同一条轨道上（不同环节的轨道倾角不同，整体有立体感）
- **轨道常显**：每个太阳脚下都有一条淡淡的轨道，选中时加深——一眼看出小球属于哪个大球
- **悬停连线**：鼠标放到小球上，会从它所属的大球拉一条虚线，并显示「数据 · 数据标注」
- **行星拖尾**：每颗行星后面带一小段光轨，能看出它在转
- **序号在球上**：外环 / 内环每个大球的球面上直接标着 ①–⑧
- **点大球（环节）**：镜头轻微推近，面板里直接列出「本环节的名词」词条（不用展开），点词条看解释
- **点小球（行星）**：直接打开这个词的「大白话 / 打个比方 / AI 什么时候用 / 什么时候会遇到」，顶部标明「属于：外环 · 数据」，并有「看这一环 →」按钮跳回对应大球
- 顶部「名词卫星」按钮：可整体显示 / 隐藏所有行星

## 名词库（和外环同一套分组）

点顶部「名词库」按钮打开。64 个名词**严格按外环 8 个环节分组**，名字和顺序与外环完全一致：

> ① 数据（6）→ ② 训练（9）→ ③ 模型（12）→ ④ 调用（11）→ ⑤ 部署（3）→ ⑥ 产品（16）→ ⑦ 成本（2）→ ⑧ 安全（5）

每组内部也按运行逻辑排序（例如数据组：数据标注 → 知识库 → 知识图谱 → 向量数据库 → 语义搜索 → 数据隐私）。

点任意名词：右侧弹出和链路同款的面板，显示「大白话 / 打个比方 / AI 什么时候用 / 什么时候会遇到」四段。

> 「AI 什么时候用」是从 AI 的视角讲：这个名词在什么任务、什么步骤里被用到；「什么时候会遇到」是从你的视角讲：你在什么场景会碰到它。
内容由《AI名词大全-64词.md》自动解析生成（`nouns-data.js`），不是手抄，改原文后重新生成即可。

> 大词归属：大模型、AGI 这类大概念放在「模型」；提示词、温度、API 放在「调用」；GPU、Token 计费放在「成本」；风险与评测放「安全」。
